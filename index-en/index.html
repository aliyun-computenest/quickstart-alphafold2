Overview

AlphaFold2 is a DeepMind-made deep learning model for protein structure prediction. This article introduces the rapid deployment AlphaFold2 of Alibaba Cloud ehpc Nvidia GPU specifications and computing nest.

Prerequisites

Billing Description

The cost of AlphaFold2 Community Edition deployment in Computing Nest mainly involves:

-Elastic High Performance Computing Cluster (EHPC) fees -File system (NAS) fees -Traffic bandwidth charges

Deployment Architecture

-deployment consists of an ehpc cluster, which includes one manager node and multiple compute nodes -manager and compute nodes are deployed on ecs instances, compute of which contains a gpu card. -The service uses nas-cpfs to build a high-performance shared file system

Deployment process

  1. Visit the Computing Nest AlphaFold2 Community Edition Deployment Link , fill in the deployment parameters as prompted:

  2. After completing the parameters, you can see the corresponding RFQ details. After confirming the parameters, click Next: Confirm Order.

  3. Confirm the order and agree to the service agreement and click Create Now Enter the deployment phase. The deployment will take several hours, and the download data will be slow. The log of the download output is stored in/root/download.log

  4. Wait for the data to be downloaded before you can start using the service. Can go to CASP14 Sample data for copy T1050 in Store it in/home/alphafold/T1050.fasta, log in through ehpc console login cluster, and enter the user name and password.

  5. Then go to ehpc console task management to execute commands.

bash -- /usr/bin/python3 /home/share/alphafold/docker/run_docker.py --fasta_paths=/home/alphafold/T1050.fasta --max_template_date=2020-05-14 --data_dir=/home/data --docker_image_name=alphafold:latest --output_dir=/home/alphafold '''

  1. Check the ehpc task status and wait for a few hours to find it. The/home/alphafold/directory generates the corresponding log (T1050.e1) and result (T1050 folder). Enter T1050 folder and copy rank_0.pdb.

  2. Results in protein structure prediction website Open rank_0.pdb in and you will see the corresponding protein structure.
